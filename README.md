# Affirmations App Android

Aplikasi Android sederhana menggunakan Jetpack Compose untuk menampilkan daftar scrollable menggunakan LazyColumn dan Card.

## Fitur
- LazyColumn
- Card
- Image Resource
- String Resource
- Jetpack Compose UI

## Struktur Project
- MainActivity.kt
- strings.xml
- drawable/

## Teknologi
- Kotlin
- Jetpack Compose
- Android Studio
